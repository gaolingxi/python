# Python 课程课件

杭州师范大学 高泠溪 老师的 Python 程序设计基础课程课件。

## 目录

- `python2026/` — 2026 版本课件（最新，`Python程序设计基础 II`）
- `python2025/` — 2025 版本课件
- `python2024/` — 2024 版本课件（含数据结构与算法 / DSE 参考课程）

每章一个子目录，主版与答案版两个 `.ipynb`：

| 章 | python2026 目录 | 主题 |
|---|---|---|
| ch1 | `1.introduction/` | Python 程序设计基础 |
| ch2 | `2.dataframe/` | 基本数据类型 |
| ch3 | `3.string/` | 字符串 |
| ch4 | `4.flow/` | 流程控制 |
| ch5 | `5.list/` | 列表 |
| ch6 | `6.dictionary/` | 字典 |
| ch7 | `7.function/` | 函数 |
| ch8 | `8.class/` | 面向对象 |
| ch9 | `9.dataframe/` | 数据框 |

## 说明

- 只包含 `.ipynb` / `.py` / `.md` / `.txt` 课件代码文件。
- 数据集（CFPS 等）、参考课程视频、PDF 教材、Anaconda 安装包等未包含，需另行获取。
- 例题统一使用「张三 / 李四」等化名。

## 许可

课程内部资料，仅供教学使用。
