# 第五章综合实践：我的食堂一周消费可视化

**适用：Python 2026，刚学完列表的学生。**

请打开 [学生作答Notebook](食堂一周消费可视化_综合实践作业.ipynb)，按顺序完成五个简单任务：

1. 填入7天食堂午饭消费金额（可实际记录，也可标注为自行模拟）。
2. 使用列表、append、sum、len、max及for循环进行简单统计。
3. 运行Notebook中**老师提供的画图模板**得到柱状图，并请AI帮助修改至少一处图表外观。
4. 根据自己的数据写两句话结论。
5. 贴一段真实AI对话，并简述自己采纳或修改了什么。

**可以使用AI**写绘图代码、调试和美化；**不需要**学习matplotlib语法，也不要求使用pandas、函数、文件读写、数据库、PPT或现场展示。

**只需提交一个**运行过的 `.ipynb` 文件，建议命名为 `学号_姓名_食堂消费.ipynb`。具体收卷平台和截止时间以教师通知为准。

**评分（100分）：** 数据与列表20分，简单统计30分，图表30分，两句话结论10分，AI记录10分。

本项目是**第五章新增的独立综合实践**，不替换现有第五章常规作业。
