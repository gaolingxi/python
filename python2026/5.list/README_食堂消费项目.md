# 第五章综合实践：食堂一周消费互动网页

**适用：Python 2026 · 刚学完列表的学生。** 原有第五章常规作业不变。

- [**学生作业 Notebook：填写7天数据 → 基础统计 → 生成网页**](食堂一周消费可视化_综合实践作业.ipynb)
- [**打开网页示例 HTML（下载到电脑后双击浏览器打开）**](食堂消费可视化_网页示例.html)

## 完成方法（五步）

1. 修改前6天消费金额，用 `money.append(...)` 加入第7天。示例金额必须改成自己的，可使用标注为“模拟”的数据。
2. 用学过的列表、`sum()`、`len()`、`max()` 和 `for` 循环完成基本统计。
3. 运行 Notebook 中第③步**教师提供的网页生成器**，生成本地 `食堂消费可视化网页.html`。双击 HTML 用浏览器打开，即可看到统计卡片、柱状图/折线图和7天消费输入框。**在网页修改金额，图表实时更新。**
4. 写两句话总结食堂消费，记录改变网页上一天金额后图表如何变化。
5. 贴一段真实 AI 帮助记录。可请AI修改 `page_title`、`primary_color`、`accent_color`；不需要学习或解释网页绘制代码。

## Python与网页怎样连接？

Notebook 的 `money` 列表 → 教师生成代码自动把数据写入 HTML → 浏览器打开互动网页。后续在浏览器输入的金额可以实时更新图表、均值和总额。

**这是不依赖服务器的单文件网页。网页不会直接修改 Jupyter Notebook 的变量。** 若希望保留网页中的改动，点击“复制更新后的列表”，粘贴到 Notebook 后再运行网页生成单元格。

## 提交与评分

**提交 `.ipynb` 和生成的 `.html`**；如果平台仅收一个附件，则压缩为 ZIP。不需要 PPT、报告或现场演示。

评分：数据与列表20分、简单统计30分、互动网页30分、结论10分、AI记录10分。

AI 允许协助绘图、美化和调试；教师只考核已经学过的 Python 列表、简单统计和循环，不考 HTML/JavaScript、pandas、Flask 或数据库。网页可以直接离线打开，不需要部署网站。
