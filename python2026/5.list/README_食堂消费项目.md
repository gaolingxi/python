# Python 2026 第五章综合实践：AI 帮我做食堂消费互动网页

> 适合刚学完 Python 列表的学生。**网页由学生自行与 AI 对话生成，不由老师提供现成的 HTML 网页或网页生成器。** 原有第五章常规作业保持不变。

[**下载／打开学生作业 Notebook**](食堂一周消费可视化_综合实践作业.ipynb)

## 作业怎么做？

1. 自己填7天午饭金额：先建立6个数字的 `money` 列表，用 `append()` 加上第7个数字（实际记录或标注为模拟数据）。
2. 用已学知识完成简单统计：`sum()`、`len()`、`max()` 和 `for` 循环。
3. **自己向 AI 提出网页需求**。把 `money` 列表交给 AI，让它帮助生成可直接在浏览器打开的独立 HTML 网页。
4. 网页应显示7天消费柱状图或折线图、总费用、日均费用、最大值，并有至少一个简单互动功能（如改动某天金额后，网页图表与总额同步变化）。
5. 生成网页后**再与 AI 对话一次**，自行提出美化或修正要求。打开网页核对结果，写两句话结论。

## 给学生的最低技术要求

- Python 只用前五章已学内容；**不要求自己会写 HTML/JavaScript**，网页代码可以让 AI 帮助生成。
- **不提供可直接复制的教师网页生成器、完整网页源码或现成成品页面**；需要学生自己与 AI 共同制作。
- 不要求网页与 Notebook 实时连接、部署网站、使用 Flask、pandas、matplotlib 或安装新软件。
- 网页中展示的7天消费及统计数据，必须与本人 Notebook 的列表和计算一致。
- 必须在浏览器**实际打开 HTML**，至少验证一个互动功能。对话记录至少两轮：首次创建、再次修改。
- 鼓励使用 AI 帮助排错和美化，但要能说明自己改了什么；无需长篇项目报告。

## 交什么？

`学号_姓名_食堂消费.ipynb` + `学号_姓名_食堂消费.html`，AI 对话记录写在 Notebook 里。若平台仅允许提交一个文件，可打包 ZIP。不需要 PPT 或现场演示。
