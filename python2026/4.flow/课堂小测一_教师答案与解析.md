## 四、代码纠错题（每题10分）

### 1. 成绩比较

```python
score = "85"
print("成绩大于80：{}".format(int(score) > 80))
```

**原因：** 原式包含字符串拼接以及字符串与整数比较，不能实现数值大小判断。应先转换 `score`，再比较；按预期文本输出。

### 2. 字符串索引

```python
s = "Hello"
print(s[0:6])
print(s[-1])
```

**原因：** `Hello` 的有效索引为0到4，`s[5]` 越界。`s[0:6]` 是合法切片，不会报错，并能输出全部字符；也可以改用 `s[0:5]`。第二行的 `s[-1]` 也可写成 `s[4]`。
